# Homepage key art

These nine WebP paintings were created for Hollow Wake's announcement trailer.
They are illustrative key art, not gameplay screenshots. The site labels them
accordingly. They are reused at their original compressed size (about 2.3 MB
combined); no video, depth maps, or entire trailer projects are duplicated.

Source: `trailer/project-v2/assets/plates/` in the owner's working project.
`necro.webp` is named `necromancer.webp` here; other names are unchanged.
The trailer's provenance ledger records Qwen-Image and Z-Image Turbo
(Apache-2.0 model weights) through NanoGPT for paintings and Real-ESRGAN
(BSD-3-Clause) for upscaling. All artwork was generated for this project;
no stock or third-party media was used. See the original `trailer/README.md`
and `trailer/pipeline/` for the production record.
