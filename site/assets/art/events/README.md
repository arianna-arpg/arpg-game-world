# Event paintings

Original Hollow Wake atmospheric illustrations generated with OpenAI's built-in
image tool on 2026-11-10. These are conceptual scenes, not gameplay screenshots.
The 36 images here supplement the existing Warbands, Conclave and Hunt paintings
in `../field-guide/`, giving every current event a distinct scene.

`../../event-art.js` maps the game's stable package IDs to the artwork. The field
guide reads names and descriptions from the normal exported game data. Future
events without a painting fall back to the field journal.

`prompts.json` records the exact generation prompt, style reference and original
PNG for each image. Originals remain in the generated-image library; the website
uses only the 960 × 640 WebP versions. To replace a scene, update its registry path
and retain the replacement's prompt and provenance here.
