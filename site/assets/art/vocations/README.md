# Vocation paintings

Six original Hollow Wake paintings generated on 2026-11-10 with built-in image
generation in the owner's chat. The original Guardian painting served as a
style reference. No stock or third-party artwork was supplied. These are
illustrative scenes, not gameplay screenshots. The tool did not expose its
underlying model version.

`prompts.json` records every prompt and original output filename. Full-size
PNGs remain in the owner's generated-image library. The website copies are
1536 x 1024 WebP conversions at quality 0.86, with no cropping or retouching.

`site/assets/vocation-scenes.js` maps stable game IDs to these images and copy.
Only paintings belonging to the selected base class can appear, and only the
selected painting loads after the visitor opens the gallery. The Greenwarden
image is not requested until the Ranger's secret calling is explicitly revealed.
New paths for a class can be added without changing the gallery layout.

## Character continuity pass — 2026-11-10

The owner requested that a Vocation retain the base class's character identity.
`lineage-prompts.json` records six edits made with built-in image generation,
using each base-class painting as the identity reference and the first Vocation
painting as the composition reference. Skin tone, facial structure, age, gender
and hair remain recognizable; attire and abilities advance with the Vocation.

- Warrior → Warbringer (`warbringer.webp`)
- Ranger → Wildstalker and Greenwarden (`wildstalker.webp`, `greenwarden.webp`)
- Magician → Spellblade (`spellblade.webp`)
- Cleric → Hierophant (`hierophant.webp`)
- Summoner → a separate Gravebinder variant (`gravebinder-summoner.webp`)

The owner's preferred `gravebinder.webp` remains unchanged for Necromancer.
The game also explicitly offers Gravebinder to Summoner, so its per-class
variant preserves that character instead of borrowing Necromancer's likeness.
The base class named Spellblade is distinct from the Magician's Vocation.
These seven web assets use the same 1536 × 1024, quality-0.86 WebP conversion.
Full-size originals remain in the owner's generated-image library.
