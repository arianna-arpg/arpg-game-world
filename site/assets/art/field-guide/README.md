# Hollow Wake — field-guide paintings

Generated with OpenAI's built-in image generation tool on 2026-11-10. Exact prompts, original filenames, and the existing Hollow Wake style reference are recorded in [prompts.json](prompts.json). Original PNGs remain in the generated-images library; these compact 960 × 640 WebP copies are used by the website.

These are atmospheric illustrations of broad environments and encounter families, not literal maps or gameplay screenshots. `site/assets/field-art.js` maps exported biome tags and event IDs to paintings; unfamiliar places use the neutral field journal. The complete exported roster remains eligible for random selection.
