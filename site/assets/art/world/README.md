# Frontier scene paintings

Three original environmental paintings generated for Hollow Wake in the owner's chat on 2026-11-09. No stock or third-party artwork was supplied. These are illustrative scenes, not gameplay screenshots. Exact prompts and original output filenames are in prompts.json. The generation tool did not expose a model version.

Original 1536 × 1024 PNGs are retained in the owner's generated-image library. The site uses WebP at quality 86, compression level 6, with no cropping or compositing. The existing memory-art renderer supplies the organic border.

Edit site/assets/world-scenes.js to replace artwork, captions or descriptions, or to add another story. Keep each ID unique and image paths relative to the homepage. Only selected scenes are requested; there is no automatic slideshow. The HTML retains the initial scene and all three descriptions as a no-script fallback.
