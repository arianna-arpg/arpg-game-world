# Retained realm gate renewal

A retained surface now retires a Crusade or Demon entrance when its event no longer qualifies on that ground. The unchanged native portal updater then places the eligible current event's entrance. A live entrance for the same qualifying event keeps its exact row and position.

The operation changes portal metadata only. It does not reload the surface, clear its actors, retire an occupied side area, reset its boss or grant rewards. Demon lookup uses the surface's actual dimension. Selected event queries and array operations retain their receiver and errors; the actual retained physical operation and captured metadata are checked before removal. Completed removals or native insertions survive a later exception, and reconciliation refuses recursive invocation.

The demonstrated failures were repeat Crusade and Demon events on already visited ground: both first bosses paid their original rewards, but the old retained entrance prevented the successor entrance from appearing. The bounded courses use supported event ignition controls, real generated surfaces and real realm plans, then invoke the actual boss kill operation. They do not claim natural player combat, browser navigation or TCP coverage. Same-event return, expired and relocated events, occupied old realms and selected callback failures have separate focused checks.

Garrison and terrain renewal are separate lifecycle work. This gate repair does not establish complete repeated-Crusade content parity, full-game parity, server capacity, private instance ownership or generated entrance structures. Historical source composition and broad integration checks belong to the combined successor.
