# Native arrival invocation boundaries

Warm retained arrivals run Warlord, Crusade, Verminfall and Vendetta in that order. Each leaf now receives one private invocation from the actual coordinator. The stage exists before readiness checks or the selected arrival getter can run, becomes claimable only for the selected call, and remains reserved through validation after that call returns. Its `finally` revokes the invocation. The selected owner reserves entry before callback-capable validation; an opaque visit token alone cannot authorize entry.

This closes an older callback-ordering gap outside the shared Crusade/Verminfall stage. A three-course diagnostic at `37fbfb25` used equal real warm-return inputs and compared normal arrival, a Warlord getter throwing a sentinel, and a captured genuine Vendetta call before that same sentinel. The early call removed the Vendetta placement marker and advanced its field RNG before scheduled Warlord entry. The native query returned no ambush. All recorded bodies, identities, wounds, global RNG and ledger facts stayed unchanged; this is not evidence of a naturally occurring duplicate or a comprehensive reward comparison.

The candidate repeats the unchanged diagnostic. It requires exact normal/control recorded facts and input equality with the parent, and the early call must fail with the specific Warlord-stage refusal before a query or any recorded effect. Additive boundary courses cover initial readiness, selected getters, native callbacks, claim validation and post-return validation. They preserve the original and retry transcripts separately, require later genuine arrivals to work, and check completed deletion, cooldown, body insertion and notice effects when a selected callback throws.

Warlord retains its existing definition validation without adding a destination occupancy query. Cross-ground crown retirement, current-crown checks and kill rewards retain their original owners. Vendetta keeps native field choices, occupancy rules, cooldowns, surviving cohorts, marker consumption and partial insertion order. Its public visit reader remains read-only inspection inside the entered Vendetta stage. Initial birth, cold reconstruction and live event placement keep their existing paths. Crusade and Verminfall live owner entry refuse throughout any pending arrival stage and resume after revocation.

An unhandled native error stops later arrivals in that transition while retaining earlier completed effects. Cleanup clears only the invocation guards and preserves the original thrown value. A later genuine transition is a new invocation; it does not roll back or replay completed work. No asynchronous arrival is admitted.

Verification includes the paired diagnostic; current arrival boundaries; original Warlord and Vendetta arrival, callback, cohort, cold and reward checks; current Crusade and Verminfall controls; retained road, travel and host courses; exact source-history checks; all four type configurations and boot. Historical test files remain preserved. Current successor maps account for every changed assertion or trigger, and historical source preservation is distinct from a current gameplay pass.

Additional validation calls occur during travel. Their cost is unmeasured here. This change makes no claim about host capacity, empty-area scheduling, transferable private state, full playable parity or main-merge readiness.
