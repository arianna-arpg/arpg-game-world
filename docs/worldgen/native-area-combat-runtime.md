NativeAreaSceneCampaignFrame preserves the original campaign statement barriers and runs four local stages over the resident areas: before actors, actors, effects, and late bodies. Each stage selects its own current admitted cohort. Global simulation, campaign clocks and shared queue drains run once. Hosted road ownership is distinct from global simulation ownership: publishing a unit area must not stop the campaign simulation or repeat its drains. Portal attendance clears departed dwell while retaining the arrival latch.

NativeAreaSceneTransitionCoordinator owns departure, admission, publication and actual queued travel. The destination and traveler are revalidated after the last live callback. A failed callback retains prior native effects; the coordinator does not manufacture rollback. Actual campaign memory views enumerate retained areas, including source areas after publication moves.

## Standalone source startup

Installed generation sources must cold-boot without importing World, the combat aggregate or the simulation arena. Record observation therefore installs no aggregate at module load. The actual combat-operation module installs its private one-use record-token resolver before its class can initialize. Binding before installation, replacing the resolver, using a foreign token or preempting genuine initialization refuses. The observer is stored only after successful resolution. This preserves independent source startup while keeping actual runtime observation tied to the aggregate's issued token.
