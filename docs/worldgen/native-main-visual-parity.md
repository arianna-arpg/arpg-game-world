# Main visual parity in native areas

This integration carries the visual and skill behavior changes from the fixed
local main reference `ea56c7ac4f5f4963dc6ad8ce3cb86bc12b66fa0b` onto retained-area
work through `0ef0f42e839666fe00b85532f36e37b8df4c8725`. The earlier reconciled
main reference was `483b00c4`. This is a pinned integration, not a claim that
remote main will remain unchanged or that every retained-area controller is
active in the playable client.

## Player-facing behavior

Skill families keep main's distinct bursts, traveling projectiles, target rites,
strikes, movement traces, self effects, storms, summons and constructs. Resource
returns distinguish life, mana, shield and flesh consumption through shape and
motion. Arrival, action and expiry visuals use the real skill identity, tier and
current geometry. The study pages and eight rendered courses travel with the
corresponding painters and catalogs.

The seamless adaptations retain world-space terrain placement, local ownership
and geographic reward levels. In particular, an orb without an explicit amount
uses `lootLevelAt(at)`. Main's ordinary `zone.level` expression cannot replace
that rule in a world spanning multiple geographic levels. A real WorldMass
regression visits levels 1 and 22 while the shared zone remains level 1 and
observes amounts 14 and 56. Explicit amounts bypass level lookup, and nested
reward scopes restore the enclosing scope even after a throw.

## Hosted and terrain rendering

ZoneW remains the canonical filtered, capped ground-field publication. Legacy
skillFields is a fallback only when zones is absent; an explicit empty zones
array clears the fields. Replicas keep skill identity, source IDs, quantized
geometry, release/arm state and live field positions. Facing is quantized for
circular fields too. onGround remains available through every field phase.
Zero-fuse fields retain the native armed/unarmed fill distinction.

The client publishes typed skill-field views from that canonical representation
and draws them once. Tether views preserve body endpoints, fallback positions,
identity, age and fade while reusing their pooled records. Projectile identity,
velocity and flight ledger remain intact alongside the added skill identity.
Existing keeper filters, actor interpolation, hosted seat data and drop ownership
stay in the wire path.

Terrain fields and terrain flashes use regionGrid/cellSize and explicit tiers.
The proof executes actual MassWalk geometry over sixteen cells; it does not
invent a tier-to-walk lookup. Controlled canvas checks also cover the restoration
ring, feeding jaws and resource flows. Rendered native courses complement those
call-level checks but do not prove complete retained network publication.

## Remaining integration

This pass does not complete retained resolveHit/kill execution, ground/follow-up
construction, effect ticking, actor retirement, scheduling, map handoff, complete
publication or durable persistence. These remain real owner services, not a
fallback to the active World. The next construction slice binds ground fields
and pending follow-ups to their actual local queues and keeps session-wide skill
banks coherent across areas.

Once complete content and controller behavior survives whole-area ownership and
paging, the bounded/open place pass can use authored zones as points of interest
and varied terrain layouts. Walls, barriers, barricades, ridges, valleys and
connected openings must affect navigation and objective placement. Hierarchy
and map zoom follow that physical and persistent foundation. These are continuing
implementation requirements, not capabilities established by this visual pass.
