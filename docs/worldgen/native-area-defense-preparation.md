# Native area defense preparation

NativeAreaSceneDefensePreparation owns admitted shell absorption, combat outcome
cues, guard-bash preparation, death-burst eligibility, rune banking and creature
drive changes. World delegates the same seven native bodies to a shared core.
Damage resolution, death execution and retained ticking remain separate work.

## Authority and live state

Each actor-bearing call requires the actual physical subject in this area's
census and its registered defense and geometry owners. Matching numeric actor
IDs or positions do not establish authority. A carried body without physical
attendance cannot mutate an area's defense state. Explicit transfer changes
which area may use the body; death alone does not remove a physically retained
actor from its census.

An active shell pool must be the victim's anatomical shell or a genuine current
worn summon shield. The latter requires the actual admitted body, live keeper
relationship, current summon skill identity and original liveness conditions.
Guard-bash preparation requires the actor's exact current casting state. These
checks follow the actual native callers, including the worn bone-golem case.

Only a null drive subject or a provably inert shell pool can return without
actor admission. The inert test inspects ordinary descriptors and never invokes
optional getters or numeric coercion. Ambiguous values require admission before
the native algorithm reads them. This is not a hostile Proxy or global-intrinsic
sandbox, and does not add a claim of individual record provenance.

The shared core reads the actual live census, flash queue and campaign time.
World's adapter follows replacement arrays and the live clock through a stable,
nonenumerable cache. The cache does not make dormancy pin unrelated census
members; genuine tether endpoints still remain visible dependencies.

order. A shell breaking before a later flash or packet-write failure retains
that earlier drain and break. Guard-bash preparation retains earlier stat
writes when a later stat read throws. No rollback or substituted combat service
is used to manufacture parity.
