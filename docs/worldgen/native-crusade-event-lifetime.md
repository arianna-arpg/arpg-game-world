# Retained Crusade event lifetime

A retained area's garrison keeps two facts: whether the current visit has already attempted its native muster, and which Crusade events have already spent a muster here. Once the native marker add completes, a later dominant event cannot pour another garrison during that uninterrupted visit. Live updates may repair a missing marker but cannot release it. The selected public event query still runs before marker repair, preserving its callback order and first failure.

A genuine warm arrival can release the visit only when no other physical Seat occupies the destination outside the arriving cohort. Standing, downed, keeper and dormant Seats all count. A never-spent current event may then muster once; returning to an already-spent event preserves its actual bodies and wounds. Crusade can have overlapping campaigns: A -> B -> A must not duplicate A's garrison. Placement history therefore retains both event-object and same-field logical-ID consumption. Logical IDs do not authorize an old commander's reward against a reconstructed event. An absent field or event cannot reopen a consumed visit during live updates; an actual empty return can release the visit before a later first eligible event appears. The existing first-birth rule for an unconsumed resident area is unchanged.

The retained owner observes the real birth operation and actual population factory. It records consumption at the completed native marker add, before discovery, monster creation or notice callbacks can remove that marker and throw. Completed native effects survive; partial garrisons and discovery cannot replay. A selected add that fails before adding does not consume a new attempt. An arrival deletion that completes and then throws keeps that deletion and the released attempt, while preserving the original error. Guard repair alone never marks an unseen successor as spent.

The coordinator privately selects Crusade after Warlord and before Verminfall and Vendetta. Selecting a callable grants no entry. Each actual invocation reserves one claim before callback-capable validation and revokes it in `finally`; foreign, sibling, repeated, live-registry and asynchronous borrowing refuse. Physical ownership and occupancy are revalidated across callbacks. This finite shared Crusade/Verminfall stage does not claim to repair the older Warlord-to-Vendetta window outside those selected event leaves.

Each native-created commander carries its issuing event identity. An ended event's commander keeps ordinary monster death effects but cannot claim another event's liberation reward or suppress its successor. A still-live older campaign resolves through a bounded field receipt for that exact event even when another campaign dominates the area. Selected callback replacement, expired identity and repeated resolution cannot redirect that receipt. Original unbound World kills retain their package behavior. The authentic lifetime calls remain captured by the defining overlay module; public zone queries remain intentionally selected.

Terrain renewal belongs to the separate [Crusade terrain lifetime](native-crusade-terrain-lifetime.md). This timing change leaves that owner, commander kill handling and realm/portal rules intact. A whole actor-count change during return can include legitimate terrain fixture renewal, so garrison tests observe the actual native muster and its inserted bodies separately.
