# Native Vendetta area lifetime

A completed Vendetta ambush no longer permanently prevents later writs on warm
retained ground. Genuine unoccupied returns release only the native per-visit
`materializedWrits` marker. Occupied areas keep the current visit. The original
field still selects one spec with its original random rolls, priority and cooldown
writes; there is no extra roll or rewritten payload.

A selected spec for a still-owned living same-writ cohort suppresses duplicate
allocation and keeps those exact bodies and wounds. Its already-completed native
cooldown write remains. Another eligible writ can be selected on a later ordinary
live call. A genuinely retired cohort may retry after a real return and the normal
cooldown. Settled or expired old cohorts do not block a different selected writ.
Old bodies retain their original `eventKey`; their ordinary native kill handler
cannot settle a different successor id. No reward or ledger effect is synthesized.

At admitted placement and unoccupied arrival boundaries, private cohort storage
forgets only bodies absent from the exact census and proven unclaimed by the
original authority. Empty cohort rows then disappear. Still-present bodies,
including corpses, remain recorded; absent-but-claimed bodies are conservatively
retained for transfers or incomplete removals. All decisions precede compaction,
and actual authority/root checks must still pass. This bounds the new owner's
references to completed retirements without claiming reclamation in other caches.

The binding consumes one private token from the actual combat owner. Cohort records
come only from the selected native placement and genuine new population-factory
insertions into its exact census. Initial birth remains separate from admitted
physical operations. A copied tag/id or saved record cannot register a cohort.
Ordinary unbound World uses the unchanged native body, field and reward rules.
No save schema changes: native cold memory omits these event bodies while the field
writ is durable; Continue uses the original fresh reconstruction/cooldown policy.

The spawn hook selects the actual theater callable and then evaluates the original
arguments. It revalidates the selected event after both steps and before invoking
that callable with its actual receiver. A getter that ends the writ cannot insert
a hunter; a body that completes an insertion before ending the writ keeps that
partial effect. The spawn-only adapter uses Reflect.apply, so an own callable
apply property is not a second delayed selection boundary. Native getter/body
exceptions retain their exact thrown identity.

Completed guard, cooldown and actor insertion effects survive native exceptions.
There is no same-visit replay after a successful marker write. A source exception
before an Actor is returned cannot grant a cohort receipt for that inserted partial
body; the body remains as the native partial effect, with its incomplete native
metadata, and is never fabricated into a warrant. Actual recorded surviving members
still prevent duplicate same-writ allocation on return.

Verification: the preserved phase199 natural two-writ comparison uses genuine
population culls and native ignition, actual first warrant kill and A-B-A travel.
Both lanes now spawn the second four-body squad and settle once. The original199
negative remains frozen. Focused courses cover surviving wounds, simultaneous writs,
expired warrants, real retirement/retry, partial guard/spawn effects, actual hosted
occupancy, false binding/visit refusal, selected callbacks, and paired real disk
Save/Continue. Game/simulation typing is a preflight before immutable review.
These are finite contracts, not whole-game parity or performance acceptance.
