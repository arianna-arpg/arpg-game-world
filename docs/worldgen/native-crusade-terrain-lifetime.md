# Retained Crusade works lifetime

This successor gives retained Crusade structures the same event/plan renewal trigger as the native arrival path. It is a bounded works-lifetime change. The accepted gate and garrison lifetime owners remain separate, and this does not establish full game parity or server capacity.

## Arrival and ownership

The actual native injected-fixture pass records the issuing event identity, tier, complete resolved structure/city-fill plan, RNG cursor, and its finite geometry delta. Authored fixtures precede that pass. The original native generation finishes afterward. The capture revalidates the actual field and selected plan around that pass and after generation; the selected public query still runs. The unbound World keeps its original fixture order and generation behavior.

An already born retained area renews only within its real transition receipt, while it has no physical player occupants. A remote occupant defers renewal. An unchanged event and resolved plan keep the actual structures, doors, furniture, wounds and fog. A changed event, tier or plan retires only the recorded works patch and compiles the current native fixture list. No whole-area geometry adoption, actor reset, reward replay or synthetic completion is performed. Expiry without a successor removes the obsolete patch.

The native fixture compiler and native reachability/navigability passes run on a private working grid. Existing unrelated structures, doors, trigger mouths, living ground-level actors, physical rewards and the waypoint are reserved. Previously reachable protected standing points must remain reachable in an open-door view before publication. Existing geometry/grid/array identities stay stable. Native fitting can reseat works to protect those retained objects, so retained structure positions need not equal a freshly regenerated World. `crusadeWorksAt` remains the native requested float anchor when seating is unchanged, and the actual structure center when fitting reseats it.

Cell retirement restores only the still-owned installed value, with the real door-opening exception. Later native generation writes are recorded even when they write the same value; temporary open-door topology checks are excluded, and grid-growth coordinates are translated. Removed underlay doodads are not reclaimed where later generated structures, new doodads or painted cells took ownership. Runtime changes outside this finite recorded patch are not a general terrain provenance system.

## Native bodies and interrupted work

The same real native door/furniture/plan/folk stages insert and admit new fixture bodies. Existing ordinary garrisons remain alive, with their wounds and event reward ownership; only obsolete slot claims are released. Retiring fixture bodies awards no kills, XP or loot. Actual native insertion records each completed row before a later callback can fail. A committed geometry patch, earlier inserted bodies and completed authority releases survive later callback exceptions. Retrying a genuine arrival completes the outstanding work without replaying completed rows. Selected queries that replace the census/geometry or move the source actor are refused before terrain effects.

## Optional saved furniture correspondence

A saved generated enemy may carry `crusadeFixture` with zone, event, tier, structure, resolved plan and fixture ordinal. Both original World adoption and extracted native character restoration copy this optional field through a bounded own-data parser. Original unbound World has no fixture observer and receives no retirement authority from it. Native enemy restoration otherwise retains its original order, positions, rarity, names and life.

A retained cold birth accepts the marker only during actual restoration into its bound genuine population, against an actual generated fixture row with matching event/plan/ordinal, actor definition and ground floor. A second live body for the same row is refused. Malformed, mismatched or absent metadata stays inert; legacy unmarked bodies remain conservatively unowned. Saved positions are preserved because a warm retained fixture may have been reseated relative to a fresh native layout. This correspondence is not a cryptographic signature: an exact valid copied marker on otherwise identical saved fixture data cannot prove historical origin.

Live grants are separate from saved parsing. The memory helper consumes only one-use tokens minted privately by the terrain defining module. There is no public registrar installer. There is one terrain owner per census; the bound population must have that exact immutable census, and each insertion is checked against the population's defining-module factory provenance. Structural owners, foreign populations, reused/foreign tokens and a second owner of a real census cannot mint receipts for actual retained bodies.

Owned door and slot IDs use zone/event/tier/fixture ordinal consistently for initial native birth and warm renewal. Native old door identifiers have a birth-only alias for older saved door rows. Real warm-renewal door opening, disk save and fresh-process Continue verify that the stable identifiers retain the open states.

## Acceptance and limits

The authored courses cover an actual two-boss native/retained journey; first-birth works with partial damage and opened doors; remote occupied deferral followed by unoccupied renewal; expiry cleanup; unchanged-plan identity; same-tier actual plan changes; selected query and source actor mutation; mark/factory failures; retirement failures before and after the actual authority release; and real launcher-backed save/Continue/renewal.

The cold course has a negative-control mode for ten malformed/mismatched markers and a legacy unmarked fixture, plus a duplicate-row refusal mode. Those controls deliberately edit only test-save metadata and recompute its existing non-security world digest to reach the intended parser; an unadjusted changed save is correctly rejected earlier by the retained world-integrity gate. The unchanged independent cold-furniture negative is retained separately and replayed against the correction.

Native generation can emit its existing unrescuable/apron diagnostics in these seeds. Calling the same native finalizers and protecting retained standing points does not prove every native door or generated point is globally reachable. Both ordinary World and retained current-zone Continue can query before the native field's first update and initially omit the event layout. The first real frame binds the field; the delayed installation rule below preserves the complete restored enemy census. Legacy unmarked furniture intentionally cannot be safely retired. Broader objective/content parity, private generated quest instances, bounded terrain design and MMORPG performance remain separate work.

The inherited historical source assertions, source archives and older failing terrain expectations remain unchanged. Integration must add exact reviewed successor projections for the bounded runtime hunks, including the two optional memo-adoption clauses, and preserve the old terrain-failure evidence. The unchanged inherited epoch boundary course passes all 13 cases on this successor and remains an acceptance gate. A prior prediction about its walk-identity assertion was disproved by actual replay and is preserved in the author correction receipt.

## Current-zone Continue and delayed works

The native enemy-memory law replaces every generated enemy with the complete saved enemy census, including a meaningful empty census. When a genuine retained cold birth completes that exact restoration with no initial event patch, it holds a private one-use completion fact. The fact is minted only after the original refreshMagicPacks callback returns and is tied to the actual population and the array that the original replacement installed. A thrown callback or replaced census cannot mint a usable completion. Foreign structural tokens cannot declare restoration complete. No new save field is introduced.

The first actual later works installation records its furniture rows as completed. It does not duplicate the restored saved furniture, respawn fixtures killed before saving or after Continue, or grant retirement ownership to any old body. Geometry, non-enemy plan/folk inhabitants and new door guards still use their existing native stages; matching saved stable door states are applied before those guards are born. The existing birth-only legacy door alias is unchanged, and unrelated door IDs receive no deferred state application.

This rule follows complete native memory, not a guess that the field event remained the same. A no-event return leaves the completion fact pending. If the event or actual plan changes before the first works installation, that first installation still honors the cold saved census, as the ordinary generate-then-restore lane does. The fact is consumed when the real patch commits; a later callback failure retains that committed suppression and pending matching door work for a genuine retry. Later ordinary event/plan renewals use the normal retained works lifetime. Saved bodies left unowned by the cold no-patch case also remain unowned on expiry, matching original native memory behavior.

The original phase175 current-zone, all-spent, post-Continue kill and new-event negative sources and evidence remain unchanged. They are replayed against the successor alongside the away-save metadata controls. Supplemental courses exercise one fixture killed before saving and one after Continue, actual saved opened doors, no-key deferral, same-event plan change, complete empty restoration, native refresh failure and replacement of the restored census. These are finite acceptance witnesses, not a claim of whole-game parity.

Saved-door replay selects the actual geometry callback once, revalidates the authentic entry/event after its getter, and invokes that selected function with the actual geometry receiver through Reflect.apply. If selection ends the event, the door writer does not run. If the actual writer opens a door and then ends the event, the completed opening remains before the post-call refusal. The original phase183 getter negative and completed-body control are preserved unchanged.
