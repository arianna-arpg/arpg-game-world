# Native area birth composition

NativeSceneBirthComposition connects the original ordered, post-arrival native
birth program to concrete local owners. All 124 ports are supplied; the earlier
remaining-callback bag is gone. The 36 native runtime rows keep their original
order. Binding alone never resets an area or publishes it into streaming.

The composition checks census, geometry, population, resident factory, objective
state, campaign, transition and shared event-state identity before birth. Harbor,
coast, descent and encounter generation share their actual transition state.
Bounty reads the same campaign as every other birth owner. Puzzle environment
services read the live objective state, including replacement and remembered
completion. A bound resident session must still belong to the same area at entry.

NativeSceneSky moves the three original sky/radiance methods to a shared host.
World delegates to it and native areas use their own environment's geyser state.
All seven event-weather sources keep their executable bodies. Native shelter,
strongest-front ordering and ties, event footprints, span painting, and the
geographic weather branch retain their original rules. The visible mechanism is
the existing sky, illumination and materialized span; no explanatory UI is added.

## Verification boundary

The complete-birth course invokes an independent archived original, current World,
and composed local owner in separate processes. The local lane refuses donor
World scene reads and birth callbacks. It compares factory calls, every body,
shared controller/body/campaign graph, geometry, event/text/notice and timeflow
side effects, both random continuations and partial failures. Resident session
transfer in this test retains prior dialogue state while rebinding its local host.
This fixture is not a production source issuer.

The objective matrix covers all 19 ObjectiveSpec dispatch kinds, including fresh
and revisited puzzles, completed-objective and remembered puzzle solves. The
lair/package/venture rows exercise synthetic dispatch; their full content is not
established by those rows. The existing runtime-birth and registry courses supply
separate native event materialization evidence. Neither proves every ongoing
controller, reward or area lifecycle is installed in seamless play.

   Streaming chunks remain subordinate to those owners; square experimental
   MassHierarchy cells are not native regions or native zones.
4. Connect revealed local terrain, native zones/events and regional knowledge to
   map zoom over those same persistent identities.

Placement continues separately. More supported native terrain seats do not replace
whole-area assembly, complete event/content ownership, persistence or map parity.
