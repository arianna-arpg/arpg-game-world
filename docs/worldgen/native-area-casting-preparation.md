# Native area casting preparation

NativeSceneCastingPreparation shares eleven original World operations for skill
payments, charge costs, ammunition and remnants, stealth consumption, combo and
meta instances, held-skill lookup and construct relocation targeting.
NativeAreaSceneCastingPreparation binds those rules to the area's physical actors,
its actual restoration owner, campaign time and seat lookup, and two raw WeakMaps.

## Authority, references and native effects

An actor-reading operation requires the actual local body and the exact registered
casting, restoration and tether owners. Matching numeric IDs, logical ownership or
a carried hero's hidden body cannot substitute for physical attendance.

The supplied comboCursors and relocationHosts state and maps have one lifetime
owner. Their keys, values and contents remain native. The slots retain their
enumerability and become nonconfigurable and readonly; these native operations
never replace the maps. Existing native shard handoff drops combo cursors.
Retained controller transfer and its map policy remain separate work.

The shared function bodies preserve the original parameters, defaults, return
types, reads, RNG consumption and partial effects. Payment can remain spent when
a later callback or ward operation throws. Actual restoration performs its own
physical check at the native point where the ward is granted.

The adapter selects live campaign and restoration methods lazily and invokes the
selected function with its real provider as receiver. Independent review reproduced
a discrepancy in the initial adapter: calling fn.apply consulted the function's
own apply property. The corrected adapter uses Reflect.apply, with regressions for
both data and accessor overrides, receiver selection and later failures.

Some native paths return before reading an actor. Descriptor-based preflight
allows only proven static cases. Ambiguous getters, custom array operations,
prototypes and coercions require admission; admitted native code retains its own
read order. This is an entry policy, not an arbitrary Proxy/global-intrinsic sandbox.

The algorithm comparison explicitly mirrors actors, flashes, maps and clock into

not prove ordinary World adapter wiring, full skill execution or native spawning.

of edited or duplicated known hunks; actual replacement maps, census and clock;
lazy callback receivers and partial failures; and dormancy after cache creation.
